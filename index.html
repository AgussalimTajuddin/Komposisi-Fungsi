Soal 2
Diketahui dua fungsi:
f(x) = 1/(2x+1) dan g(x) = 2x² + 1
a. Menentukan (f ∘ g)(x)
Substitusikan g(x) ke dalam fungsi f:
(f ∘ g)(x) = f(g(x)) = f(2x² + 1)
= 1/(2(2x² + 1) + 1) = 1/(4x² + 3)
Jawaban: (f ∘ g)(x) = 1/(4x² + 3)
b. Menentukan (g ∘ f)(x)
Substitusikan f(x) ke dalam fungsi g:
(g ∘ f)(x) = g(f(x)) = g(1/(2x+1))
= 2(1/(2x+1))² + 1
= 2/(2x+1)² + 1
Atau: (4x² + 4x + 3)/(2x+1)²
Jawaban: (g ∘ f)(x) = (4x² + 4x + 3)/(2x+1)²
c. Domain dan Range dari (f ∘ g)(x)
1. Domain: Penyebut 4x² + 3 ≠ 0. Karena 4x² ≥ 0, maka 4x² + 3 ≥ 3 > 0 selalu benar.
2. Range: Nilai minimum 4x² + 3 adalah 3 (saat x=0). Maka nilai maksimum fungsi adalah 1/3. Saat x → ∞, nilai mendekati 0.
📌 Domain dan Range (f ∘ g)(x):
Df∘g = ℝ
Rfg = (0, 1/3]
d. Domain dan Range dari (g ∘ f)(x)
1. Domain: (2x+1)² ≠ 0 → x ≠ -1/2
2. Range: Karena 2/(2x+1)² > 0, maka 2/(2x+1)² + 1 > 1.
📌 Domain dan Range (g ∘ f)(x):
Dg∘f = ℝ \ {-1/2}
Rg∘f = (1, ∞)
Soal 3
Jika f(x) = 6x - 5 dan g(x) = ax + b, tentukan a dan b sehingga (f ∘ g)(x) = (g ∘ f)(x).
1. (f ∘ g)(x) = f(ax + b) = 6(ax + b) - 5 = 6ax + 6b - 5
2. (g ∘ f)(x) = g(6x - 5) = a(6x - 5) + b = 6ax - 5a + b
3. Samakan: 6ax + 6b - 5 = 6ax - 5a + b
→ 6b - 5 = -5a + b
→ 5a + 5b = 5
→ a + b = 1
Kesimpulan: Nilai a dan b adalah setiap pasangan bilangan real yang memenuhi a + b = 1 (atau b = 1 - a).
Contoh: Jika a = 0, maka b = 1. Jika a = 2, maka b = -1.
Soal 4
Hasil dari (f ∘ g)(x) = (2x + 3)³ sedangkan f(x) = x³. Tentukan g(x).
f(g(x)) = (g(x))³
Samakan dengan soal: (g(x))³ = (2x + 3)³
Ambil akar pangkat 3 kedua ruas: g(x) = 2x + 3
Kesimpulan: Fungsi g(x) = 2x + 3.

Soal 6
Jika f(3) = 7, g(3) = 6, f(6) = 13, g(6) = 12, tentukan (f g)(3).
(f ∘ g)(3) = f(g(3))
Karena g(3) = 6, maka:
f(g(3)) = f(6)
Karena f(6) = 13, maka hasilnya 13.
Kesimpulan: Nilai dari (f ∘ g)(3) adalah 13.
Soal 7
Fungsi kertas: k(x) = 250(x + 1). Fungsi biaya: b(k) = 400k + 20.000. Total biaya = Rp10.120.000.
1. Cari total kertas (k):
400k + 20.000 = 10.120.000
→ 400k = 10.100.000
→ k = 25.250

2. Cari jumlah eksemplar (x):
250(x + 1) = 25.250
→ x + 1 = 101
→ x = 100
Kesimpulan: Banyak eksemplar modul yang dicetak adalah 100 eksemplar.
Soal 8
Produksi Android = 2 × produksi bukan Android. Produksi Laptop = 3 × produksi Android.
Misal x = bukan Android.
A(x) = 2x (Android)
L(A) = 3A (Laptop)
Mesin Komposisi: (L ∘ A)(x) = L(2x) = 3(2x) = 6x

Jika x = 2.000:
(L ∘ A)(2.000) = 6 × 2.000 = 12.000
Kesimpulan: Banyak laptop yang dihasilkan adalah 12.000 unit.
Soal 9
Pajak meja = 7,5%. Biaya angkut = Rp20.000. x = harga meja.
a. Fungsi t(x) (harga + pajak)
Jawaban: t(x) = x + 0,075x = 1,075x
b. Fungsi f(x) (harga + angkut)
Jawaban: f(x) = x + 20.000
c. Komposisi dan Perbandingan
(f ∘ t)(x) = f(1,075x) = 1,075x + 20.000
(t ∘ f)(x) = t(x + 20.000) = 1,075(x + 20.000) = 1,075x + 21.500
Karena 1,075x + 20.000 < 1,075x + 21.500, maka (f ∘ t)(x) lebih murah.
Jawaban: Fungsi yang memberikan biaya lebih kecil adalah (f ∘ t)(x).
d. Kesesuaian dengan Perda
Perda tidak melegalkan pajak pada biaya angkut. Pada (f t)(x), pajak 7,5% hanya dikenakan pada x (harga meja), lalu biaya angkut ditambahkan terpisah. Sedangkan pada (t ∘ f)(x), biaya angkut ikut dikalikan 1,075 (dikenai pajak).
Jawaban: Fungsi yang sejalan dengan perda adalah (f ∘ t)(x).
